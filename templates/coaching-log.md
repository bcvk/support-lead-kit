# Coaching log

One entry per coaching conversation. Keep it short enough that you actually fill it in. The point is the commitment and the follow up date, not the narrative.

| Field | Entry |
|---|---|
| Agent | |
| Date | |
| Trigger | QA score / customer complaint / metric drop / agent asked / routine 1:1 |
| Evidence reviewed | Ticket IDs, metric and period, calibration result |
| What we saw (facts, not judgments) | |
| Agent's own read of it | |
| Root cause we agreed on | Knowledge gap / process gap / tooling / workload / motivation / unclear expectation |
| One behavior to change | Specific and observable. "Confirm the customer's goal in the first sentence" not "be more empathetic" |
| How we will know it changed | Metric or QA criterion, target, by when |
| Support from me | Shadowing, macro update, pairing, training module, removing a blocker |
| Follow up date | |
| Follow up result | Improved / partly / no change, with evidence |

## Writing the feedback

Use the SBI shape and keep each part to one sentence:

* Situation: "In ticket 48213 on Tuesday, the customer asked for a refund and a plan change."
* Behavior: "You answered the refund and did not mention the plan change."
* Impact: "They had to write back, which pushed resolution to day three and the CSAT came in at 2."

Then stop talking and ask what they would do differently. Write their answer, not yours, into the "one behavior" row. People keep commitments they phrased themselves.

## What not to log

Anything about the person rather than the work. Health, family, mood, personality labels. If it matters to the plan ("reduced hours until March"), write the constraint, not the reason.
